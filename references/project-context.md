## 文档

- PRD 文档：`https://<你的租户>.feishu.cn/wiki/<node_token>`
- docx token：`<obj_token>`（解析：`lark-cli wiki +node-get --as user --node-token "<url>"`）
- 章节结构（示例，按你的 PRD 模板调整）：
  前言 / 版本信息 / 变更日志 / 需求背景 / 需求范围 / 功能详细说明（产品流程图 · 交互原型图 · 功能说明表）/ 非功能需求 / 项目规划 / 附录；埋点仅在本次明确要求时加入
- 变更日志的变更人：`<维护者姓名>`

## 内容口径

按项目实际情况维护，例如：

- 术语与产品名写法：产品名统一写作「XX」
- 数字格式：分数按百分制展示（× 100 四舍五入）
- 时间格式：`月-日 时间点`（如 10-15 11:43）
- 展示口径：对用户不展示具体分数
- 文案要求：页面文案与内部逻辑一致
- 既有页面：`<设计稿或页面引用>`；记录本次复用的入口、布局和新增状态

## 本地资产（workspace 相对路径）

| 文件 | 用途 |
|---|---|
| `<项目>/原型.html` | 交互原型（单文件 HTML） |
| `<项目>/build/flow.mmd` | 产品流程图 mermaid 源 |
| `<项目>/build/table.xml` | 功能说明表全表 XML |
| `<项目>/build/render-*.cjs` | HTML → PNG 渲染脚本 |

```bash
NODE_PATH=<node workspace>/node_modules node render-html.cjs <输入.html> <输出.png> 390 844 2
```
